# 📨 Telegram-бот пересылки сообщений

Простой бот-посредник без форм и меню:

1. Пользователь пишет боту (включая `/start`) — бот **пересылает** сообщение в рабочую группу.
2. Кто-то в группе отвечает **реплаем** на пересланное сообщение — бот отправляет ответ пользователю
   (и ставит 👍 на ответ в группе, если доставка прошла):

   ```
   💬 Ответ от @username:

   текст ответа
   ```
   Если у отвечающего нет username — вместо него показывается его ID.
3. Переписка может идти сколько угодно раз в обе стороны.

## ⚙️ Правила

| | Пользователь (личка с ботом) | Рабочая группа |
|---|---|---|
| Типы сообщений | только текст | любые (текст, фото, файлы, стикеры…) |
| Антифлуд / антиспам | да | **нет**, без ограничений |
| Кол-во сообщений | ограничено лимитом | без лимита |

**Антифлуд/антиспам для пользователей** (настраивается в `.env`):
- минимальная пауза между сообщениями — `FLOOD_MIN_INTERVAL` (1.5 сек);
- не более `FLOOD_MAX_MESSAGES` (10) сообщений за `FLOOD_WINDOW` (60 сек), иначе мут на `FLOOD_MUTE_SECONDS` (300 сек);
- повтор одного и того же текста в течение `DUPLICATE_WINDOW` (60 сек) игнорируется;
- максимальная длина сообщения — `MAX_TEXT_LENGTH` (2000 символов);
- предупреждения отправляются не чаще раза в 10 секунд, чтобы бот сам не спамил.

Администраторы бота под ограничения не попадают.

## 🚀 Запуск

```bash
pip install -r requirements.txt
```

Создайте файл `.env` рядом с `bot.py`:

```env
BOT_TOKEN=123456:ABC...
SUPER_ADMIN_ID=123456789
# необязательно — можно задать командой /setgroup
GROUP_ID=-1001234567890
```

```bash
python bot.py
```

### Подключение группы
1. Добавьте бота в группу (реплаи на свои сообщения и команды бот получает даже с включённым Privacy Mode).
2. Напишите в группе `/setgroup` от имени администратора бота.

## 🛠 Команды администратора (в личке с ботом)

| Команда | Что делает |
|---|---|
| `/admin`, `/help` | список команд |
| `/setgroup` | в группе — сделать её рабочей; в личке — `/setgroup -100…` |
| `/group` | текущая группа и проверка доступа |
| `/texts` | все тексты бота и их ключи |
| `/settext ключ текст` | изменить текст (жирный, курсив, ссылки, премиум-эмодзи сохраняются) |
| `/settext ключ -` | отключить сообщение (`welcome`, `sent`, `banned`) |
| `/resettext ключ` | вернуть текст по умолчанию |
| `/ban ID`, `/unban ID` | блокировка пользователя |
| `/stats` | статистика |
| `/addadmin ID`, `/deladmin ID`, `/admins` | управление админами (только супер-админ) |

**В рабочей группе** (реплаем на сообщение пользователя): `/ban`, `/unban`, `/who` — последняя
показывает имя, username и ID пользователя (полезно, если у него скрыта пересылка).

### Тексты
| Ключ | Когда отправляется | Плейсхолдеры |
|---|---|---|
| `welcome` | ответ на `/start` | `{first_name}`, `{last_name}` |
| `sent` | после каждого сообщения пользователя (по умолчанию отключён) | — |
| `reply` | ответ из группы | `{author}`, `{text}` |
| `only_text` | прислали не текст | — |
| `too_long` | слишком длинное сообщение | `{max}` |
| `flood` | слишком часто | — |
| `duplicate` | повтор того же текста | — |
| `muted` | мут за спам | `{minutes}` |
| `banned` | пользователь заблокирован | — |
| `unavailable` | не удалось переслать в группу | — |
| `delivery_failed` | (в группу) ответ не доставлен | `{user_id}` |

Значения по умолчанию лежат в `texts.json`, изменённые — в базе.

## 📁 Структура

```
bot.py              # запуск, подключение роутеров и антифлуда
config.py           # настройки из .env
database.py         # SQLite: пользователи, связи сообщений, админы, настройки, тексты
texts.json / texts.py  # тексты по умолчанию и их подстановка
filters.py          # проверки: админ, рабочая группа
middleware.py       # антифлуд/антиспам (только для лички)
handlers/
  user.py           # пересылка сообщений пользователя в группу
  group.py          # ответы реплаем из группы пользователю, /ban /unban /who
  admin.py          # команды администратора
```
