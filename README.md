# Бот-модератор для Telegram-групп

Модерация, защита чата, триггеры, статистика и игры. Рассчитан на дешёвый VPS и на один процесс,
в котором работают общий основной бот и необязательные платные клоны со своим именем.

План работ: [docs/ROADMAP.md](docs/ROADMAP.md). Сейчас готовы этапы 1 и 2: ядро и модерация.

## Установка

Сервер Ubuntu или Debian:

```bash
git clone https://github.com/dalmatinec/express.git && cd express
bash deploy/install.sh
```

Скрипт поставит Docker, спросит токен бота и ваш Telegram ID, создаст пароль базы и ключ шифрования.

- Логи: `docker compose logs -f bot`
- Обновление: `bash deploy/update.sh`

## Команды модерации

Работают в группах, только у админов с правом блокировать участников. Обычному участнику бот молчит.
Вместо `/` можно писать `!`, и есть русские варианты.

| Команда | Варианты | Что делает |
|---|---|---|
| `/ban [срок] [причина]` | `бан`, `tban` | бан, без срока навсегда |
| `/unban` | `разбан` | снять бан |
| `/mute [срок] [причина]` | `мут`, `tmute` | мут, без срока навсегда |
| `/unmute` | `размут` | снять мут |
| `/kick [причина]` | `кик` | исключить, человек может вернуться |
| `/warn [причина]` | `варн`, `пред` | предупреждение, при 3 из 3 мут на сутки |
| `/unwarn` | `разварн`, `снятьпред` | снять последнее предупреждение |
| `/warns` | `варны`, `преды` | сколько предупреждений |
| `/history` | `история` | последние 10 записей о человеке |
| `/journal` | `журнал` | последние 15 записей чата |

Кого наказать: ответьте на сообщение, укажите `@username`, ID или упомяните человека.
Срок: `30с`, `10м`, `2ч`, `3д`, `1н`, `1д12ч`, `2 часа`, `навсегда`, от 30 секунд до 366 дней.

```
/mute @vasya 2ч спам
!бан 123456789 7д реклама
/warn флуд           (ответом на сообщение)
```

После команды бот удаляет её и присылает маленькую карточку с кнопкой «Снять». Анонимного админа
бот просит нажать кнопку: только так Telegram показывает, кто это, и можно проверить его права.

## Служебные команды

| Команда | Где | Что делает |
|---|---|---|
| `/ping` | в группе для админов | проверка, что бот на связи |
| `/me` | в группе | ваши сообщения в этом чате и во всех чатах с этим ботом |
| `/start`, `/status` | в личке, только владельцы | память, очередь, кэш, число чатов |

Личка бота пока работает только для владельца, остальным бот там не отвечает.

Бот сам регистрирует чат при добавлении, следит за своими правами и переносит настройки и счётчики,
когда группа становится супергруппой.

## Как устроена скорость

- **Один процесс на всех ботов.** Клон добавляет цикл опроса, а не отдельный процесс и не отдельное подключение.
- **Статистика пачками.** Счётчики копятся в памяти и пишутся одной транзакцией раз в 5 секунд.
- **Кэш в памяти.** Настройки чатов и права админов не требуют запроса на каждое сообщение.
- **Состояния диалогов.** aiogram спрашивает их на каждое событие, поэтому чтение идёт только из памяти.
- **Один фильтр на все команды модерации.** Он проверяется на каждом сообщении, поэтому не плодим обработчики.
- **Индексы под запросы.** Счётчики не входят в индексы таблицы `members`, поэтому их частые обновления не раздувают индексы.
- **Ограничение нагрузки.** Общий лимит одновременно обрабатываемых событий не даёт памяти расти при всплеске.
- **Настройка Postgres и Python.** См. `deploy/postgres.conf` и `bot/__main__.py`.

## Разработка

```bash
pip install -r requirements-dev.txt
ruff check .
TEST_PG_DSN=postgresql://postgres:postgres@localhost:5432/test pytest -q
```

Без `TEST_PG_DSN` тесты с настоящей базой пропускаются, а без aiogram и asyncpg пропускаются сквозные тесты.
