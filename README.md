# PostBot

Бот для постов в Telegram-каналы. Собираешь пост прямо в боте: текст с премиум-эмодзи, фото или видео,
кнопки любого цвета с иконками. Потом публикуешь в один или сразу в несколько каналов, сейчас или по времени.
Все посты остаются в истории: оттуда можно опубликовать повторно, изменить, переименовать или удалить.

## Что умеет

- Пост из текста, фото, видео, GIF, файла или аудио. Жирный, курсив, ссылки, спойлеры, цитаты и премиум-эмодзи сохраняются как есть
- Можно переслать готовый пост из канала, кнопки со ссылками подтянутся сами
- Кнопки трёх видов: открывают ссылку, копируют текст (например промокод), показывают всплывающее окно
- Цвет кнопки меняется одной кнопкой по кругу: обычная, синяя, зелёная, красная. Премиум-эмодзи как иконка кнопки
- Кнопки двигаются стрелками по одному шагу, до трёх в ряд, предпросмотр поста меняется сразу
- Кнопки можно добавить по одной или сразу списком одним сообщением
- Настройки поста: без звука, запрет пересылки, медиа под спойлером, текст над медиа, превью ссылки,
  закрепить после публикации, автоудаление через время
- Публикация куда угодно по желанию: себе в личку, в каналы, в группы. Сразу или по времени
- Готовые посты из истории меняются прямо в них: текст, медиа, кнопки, настройки. Потом можно обновить пост
  там, где он уже вышел, или опубликовать заново
- История: изменить, опубликовать повторно, переименовать, копия, удалить везде, где вышел, удалить из истории
- Каналы подключаются сами, когда бота добавляют админом, или кнопкой выбора канала
- Админы: владелец даёт доступ людям и выбирает, в какие каналы им можно постить
- Бэкап раз в сутки владельцам в личку, один файл заменяет прошлый. С этим файлом бот переезжает
  на другой сервер или на новый токен со всеми постами
- В чате всегда чисто: бот удаляет свои старые экраны и ваши сообщения после того, как их прочитал

## Установка на сервер

Подойдёт любой самый дешёвый VPS на Ubuntu или Debian, боту хватает 256 МБ памяти.

1. Создайте бота в [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID, например в [@userinfobot](https://t.me/userinfobot).
3. Зайдите на сервер по SSH и выполните:

```bash
apt update && apt install -y git
git clone https://github.com/dalmatinec/express /opt/postbot
bash /opt/postbot/deploy/install.sh
```

Скрипт спросит токен, ваш ID и часовой пояс, поставит всё нужное и запустит бота как сервис systemd.
Бот сам поднимется после перезагрузки сервера и после падения.

Логи: `journalctl -u postbot -f`
Перезапуск: `systemctl restart postbot`
Остановить: `systemctl stop postbot`

Настройки лежат в `/opt/postbot/.env`, пример в `.env.example`.

### Обновление

```bash
bash /opt/postbot/deploy/update.sh
```

### Через Docker

```bash
git clone https://github.com/dalmatinec/express postbot && cd postbot
cp .env.example .env    # впишите BOT_TOKEN и OWNER_IDS
docker compose up -d --build
```

Данные лежат в папке `./data`.

## Бэкап и переезд

Каждый день в 04:00 (время меняется в Админке) бот делает бэкап: база и все медиа в одном zip-файле.
Файл приходит всем владельцам из `OWNER_IDS` в личку с ботом, прошлый файл из чата удаляется.
На сервере тоже всегда лежит один файл: `data/backup.zip`. Сделать бэкап вручную: Админка, Бэкап, Сделать сейчас.

**Переезд на другой сервер:** ставите бота на новом сервере как обычно, дальше в боте Админка, Бэкап,
Восстановить из файла, и присылаете файл. Либо сразу при установке:

```bash
bash /opt/postbot/deploy/install.sh /root/backup.zip
```

**Новый токен (новый бот):** запускаете бота с новым токеном и восстанавливаете бэкап так же.
Все посты, кнопки, история, каналы и админы переедут. Медиа бот сам перезальёт с диска.
Нового бота нужно добавить админом в каналы, бот сам напишет, в какие именно.

Если файл бэкапа больше 20 МБ, через Telegram его восстановить не получится (бот не может скачивать
файлы больше 20 МБ), тогда только командой на сервере, как выше.

## Как пользоваться

**1. Подключить канал.** Админка, Каналы, Подключить. Внизу появится кнопка 📢 Выбрать канал: Telegram сам
покажет ваши каналы и добавит туда бота с нужными правами. Или просто добавьте бота админом в канал руками,
он подключится сам и напишет вам. Боту нужны права: публиковать, изменять и удалять сообщения.

**2. Создать пост.** Кнопка 📝 Создать пост, пришлите текст (можно сразу с фото или видео) или перешлите
готовый пост. Сверху появится предпросмотр, под ним панель.

**3. Кнопки.** 🔘 Кнопки, ➕ Добавить кнопку: текст кнопки, что она делает, ссылку или текст. Если в начале
текста поставить премиум-эмодзи, оно станет иконкой кнопки.

**4. Цвет и порядок.** В 🔘 Кнопки нажмите на любую кнопку, она станет выбранной 👉. Под ней появятся:
- стрелки ⬅️ ⬆️ ⬇️ ➡️, одно нажатие один шаг. ⬆️ ставит кнопку в ряд выше, если там меньше трёх кнопок.
  Если ряд выше полный, кнопка уходит отдельным рядом. ⬇️ так же вниз, ⬅️ ➡️ двигают внутри ряда
- ↕️ Отдельно: вынести кнопку из ряда в свой ряд
- 🎨 Цвет: одна кнопка, каждое нажатие следующий цвет по кругу
- ✏️ Текст, ссылка, иконка и 🗑 Удалить

Нажмите другую кнопку, чтобы выбрать её. Предпросмотр поста сверху меняется сразу.

**5. Опубликовать.** 📤 Опубликовать, бот спросит название (оно видно только в истории, чтобы разбираться,
где какой пост). Дальше отмечаете, куда: 📥 себе в личку, каналы, группы, в любом сочетании.
Жмёте Опубликовать сейчас или По времени.

**6. История.** 🗂 История постов, нажимаете на пост. Там всё: где он сейчас висит со ссылками, что отложено.
✏️ Изменить открывает сам пост: меняете текст, медиа, кнопки, всё сохраняется сразу. Потом
🔄 Обновить там, где он уже вышел, или 📤 Опубликовать заново. Ещё там переименование, копия и удаление.

На любом шаге есть Назад или Отмена, а /start всегда возвращает в меню.

### Кнопки списком

Одним сообщением, каждая строка это ряд, кнопки в одном ряду через `|`. Сначала текст, в конце ссылка:

```
Наш канал - https://t.me/channel
Чат @chat | Сайт site.com
```

### Время для отложенных

`18:30` (сегодня, а если время прошло, то завтра), `25.10 12:00`, `25.10.2026 12:00`, `завтра 10:00`,
`+30м`, `+2ч`, `+1д`. Время по поясу из `TZ_NAME`.

### Премиум-эмодзи

Telegram показывает премиум-эмодзи от бота, только если у аккаунта, который создал бота в @BotFather,
есть Telegram Premium. Но в каналы бот может отправлять премиум-эмодзи, только если у него куплен
коллекционный юзернейм на Fragment, без него Telegram заменяет их обычными.

Поэтому есть публикация 📥 себе в личку: там пост приходит со всеми премиум-эмодзи и кнопками.

### Всплывающие окна

Текст всплывашки бот берёт из своей базы, поэтому такие кнопки работают, пока бот запущен и пост есть в истории.
Кнопки-ссылки и кнопки копирования работают всегда.

## Как устроен код

```
postbot/
  __main__.py        запуск
  config.py          настройки из .env
  app.py             общий контейнер: база, бот, доступ, время
  db.py              база SQLite и миграции
  models.py          классы под строки из базы
  ui.py              кнопки и экраны (один экран бота в чате)
  states.py          шаги, где бот ждёт сообщение
  middlewares.py     доступ только владельцам и админам
  restore.py         восстановление бэкапа с сервера
  handlers/
    common.py        /start и меню
    editor.py        конструктор поста и настройки
    buttons.py       кнопки поста
    publish.py       выбор каналов и время
    history.py       история постов
    admin.py         каналы, админы, бэкап
    chats.py         события каналов и всплывашки
    fallback.py      всё остальное
  services/
    posts.py         посты и кнопки в базе
    render.py        как пост отправляется и правится в Telegram
    publisher.py     публикация, правка, удаление, отложенные
    media.py         медиа на диске и file_id
    backup.py        бэкап и восстановление
    jobs.py          фоновые задачи
  utils/
    layout.py        перемещение кнопок по рядам
    text.py          текст, ссылки, кнопки списком
    when.py          разбор времени
deploy/              установка на сервер
tests/               тесты на фейковом Telegram
```

Тесты: `python -m unittest -v`
