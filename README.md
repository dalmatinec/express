# 📨 Telegram-бот пересылки сообщений

Бот-посредник между клиентами и командой поддержки/продаж. Клиент пишет боту → сообщение
появляется в рабочей группе → любой участник группы отвечает реплаем → ответ приходит клиенту.
Без форм, заявок и меню для клиента — только переписка.

---

## 🧭 Что делает бот

### Клиент (личка с ботом)
1. Нажимает `/start` — бот **пересылает** `/start` в рабочую группу (чтобы команда видела нового
   клиента) и отвечает клиенту приветствием.
2. Пишет любой текст — бот **пересылает** его в группу. Переписка не ограничена по количеству
   сообщений, но защищена от флуда (см. ниже).
3. Получает ответы из группы в виде:
   ```
   💬 Ответ от @username:

   текст ответа
   ```
   Если у отвечающего нет username — вместо него показывается его ID.

Что принимается от клиента: **только текст**. На фото, стикеры, голосовые и т.п. бот отвечает,
что принимаются только текстовые сообщения.

### Рабочая группа
- Обычная группа Telegram, её участникам **не нужно** быть админами бота.
- Любой участник нажимает «Ответить» (reply) на пересланное ботом сообщение и пишет ответ —
  бот отправляет его клиенту. Можно отвечать **сколько угодно раз** и чем угодно: текст, фото,
  файлы, голосовые, стикеры. Ограничений и антифлуда в группе нет.
- После доставки бот ставит 👍 на ответ. Если доставить не удалось (клиент заблокировал бота) —
  бот пишет об этом в группу.
- Обычная переписка в группе (без реплая на сообщение бота) ботом игнорируется.
- Админы бота могут в группе ответить на сообщение клиента `/ban` или `/unban`.
  У остальных участников эти команды не работают.

### Админы
- Когда админ пишет боту `/start` или `/admin`, открывается **админ-панель**.
- **Ничего из того, что админ пишет боту, в группу не пересылается** — операторы не примут
  админа за клиента. Проверять бот «глазами клиента» нужно со второго аккаунта (не админа).

## 🛠 Админ-панель

Открывается командой `/start` или `/admin` в личке с ботом. Всё управляется кнопками.

```
🛠 Админ-панель
👥 Рабочая группа: -100…
👤 Пользователей: 120 (активны за сутки: 14)
🚫 Заблокировано: 2
👮 Админов: 3

[👮 Администраторы] [🚫 Блокировки]
[📝 Тексты]         [👥 Рабочая группа]
[📊 Статистика]     [❓ Как работает бот]
```

### 👮 Администраторы
- **Просмотр:** список всех админов с именами, чтобы было понятно, чей это ID:
  ```
  👑 Иван Главный (@boss) — 111111111
  👮 Пётр Продавец (@seller) — 222222222
  👮 Без имени — 333333333
  ```
  Имена обновляются автоматически, если человек сменил их в Telegram.
- **Добавить** (➕) — отправить ID человека или переслать боту любое его сообщение.
- **Удалить** — нажать на кнопку «❌ Удалить: Имя».
- Добавлять и удалять может только **супер-админ** 👑 (его ID задаётся в `.env`, удалить его нельзя).
  Обычные админы видят только список.

> «Без имени» появляется, если добавить по ID человека, который ни разу не писал боту —
> Telegram не отдаёт его имя. Лучше добавлять пересылкой его сообщения.

### 🚫 Блокировки
- Список заблокированных клиентов с именами.
- «✅ Разблокировать: Имя» — снять блокировку.
- «➕ Заблокировать по ID» — ID или пересланное сообщение клиента.
- Заблокированный клиент получает текст `banned` и его сообщения в группу не попадают.

### 📝 Тексты
Каждый текст можно открыть, посмотреть, как он выглядит, **изменить** или **вернуть по умолчанию**.
Форматирование (жирный, курсив, ссылки, премиум-эмодзи) сохраняется. Отправьте `-`, чтобы
сообщение вообще не отправлялось.

| Ключ | Когда отправляется | Плейсхолдеры |
|---|---|---|
| `welcome` | клиенту в ответ на `/start` | `{first_name}`, `{last_name}` |
| `sent` | клиенту после каждого сообщения (по умолчанию отключён) | — |
| `reply` | ответ из группы клиенту (отключить нельзя) | `{author}`, `{text}` |
| `only_text` | клиент прислал не текст | — |
| `too_long` | слишком длинное сообщение | `{max}` |
| `flood` | клиент пишет слишком часто | — |
| `duplicate` | клиент повторил тот же текст | — |
| `muted` | временный мут за спам | `{minutes}` |
| `banned` | клиент заблокирован | — |
| `unavailable` | не удалось переслать в группу | — |
| `delivery_failed` | в группу: ответ не доставлен | `{user_id}` |

Тексты по умолчанию лежат в `texts.json`, изменённые — в базе.

### 👥 Рабочая группа
- Показывает текущую группу и видит ли её бот.
- **Сменить группу:** добавить бота в новую группу и написать там `/setgroup` от имени админа
  бота — или нажать «✏️ Указать ID группы» и отправить ID.

### 📊 Статистика
(также командой `/stats`)
- 👤 всего пользователей;
- 🆕 новых за сутки и за 7 дней;
- 🟢 активных (писали боту) за сутки, 7 и 30 дней;
- 🚫 заблокированных;
- 📨 сообщений от клиентов в группу (всего и за сутки);
- 💬 ответов из группы клиентам;
- 👮 админов.

Считается только количество — тексты сообщений не хранятся.

### ❓ Как работает бот
Краткая справка прямо в боте + список текстовых команд.

## ⌨️ Текстовые команды (дублируют панель)

| Команда | Где | Кто | Что делает |
|---|---|---|---|
| `/start`, `/admin` | личка | админы | открыть админ-панель |
| `/help` | личка | админы | список команд |
| `/setgroup` | в группе | админы | сделать эту группу рабочей |
| `/setgroup ID`, `/group` | личка | админы | задать / проверить группу |
| `/texts`, `/settext ключ текст`, `/resettext ключ` | личка | админы | тексты |
| `/ban`, `/unban` (реплаем на сообщение клиента) | группа | админы | блокировка |
| `/ban ID`, `/unban ID` | личка или группа | админы | блокировка по ID |
| `/addadmin`, `/deladmin` (реплаем на сообщение человека) | группа | супер-админ | добавить / удалить админа |
| `/addadmin ID`, `/deladmin ID`, `/admins` | личка или группа | супер-админ | админы по ID, список |
| `/stats` | личка | админы | статистика |

## 🛡 Антифлуд / антиспам (только для клиентов)

Настраивается в `.env`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `FLOOD_MIN_INTERVAL` | 1.5 | минимальная пауза между сообщениями, сек |
| `FLOOD_MAX_MESSAGES` / `FLOOD_WINDOW` | 10 / 60 | не больше 10 сообщений за 60 сек… |
| `FLOOD_MUTE_SECONDS` | 300 | …иначе мут на 5 минут (сообщения молча игнорируются) |
| `DUPLICATE_WINDOW` | 60 | повтор того же текста в течение 60 сек игнорируется |
| `MAX_TEXT_LENGTH` | 2000 | максимальная длина сообщения |

Предупреждения клиенту отправляются не чаще раза в 10 секунд, чтобы бот сам не спамил.
На рабочую группу и админов ограничения не действуют.

## 💾 Что хранится в базе (SQLite)

- **users** — ID, имя, username клиента, отметка о блокировке, дата первого и последнего сообщения;
- **links** — связь «ID пересланного сообщения в группе → ID клиента» (**без текста**), нужна,
  чтобы ответ реплаем ушёл нужному человеку;
- **admins** — ID, имя и username админов;
- **settings** — ID рабочей группы;
- **texts** — тексты, изменённые через панель;
- **counters** — счётчик ответов для статистики.

История сообщений и заказов **не хранится**.

## 🚀 Установка и запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # и заполнить
python bot.py
```

`.env`:
```env
BOT_TOKEN=123456:ABC...        # токен от @BotFather
SUPER_ADMIN_ID=123456789       # ваш Telegram ID (супер-админ)
# GROUP_ID=-1001234567890      # необязательно — можно задать в панели или /setgroup
```

**Подключение группы:** добавьте бота в группу и напишите там `/setgroup` (от имени админа бота).
Отключать Privacy Mode не нужно — реплаи на свои сообщения и команды бот получает и так.

## 🔄 Обновление бота на сервере (systemd)

База от старой версии бота не подходит — начинаем с чистой. Ниже `mybot` — имя вашего сервиса,
`/opt/express` — папка с ботом; подставьте свои.

**1. Узнать имя сервиса и папку**
```bash
systemctl list-units --type=service | grep -i bot
systemctl cat mybot          # WorkingDirectory= — папка, ExecStart= — чем запускается (python или venv)
```

**2. Остановить бота**
```bash
sudo systemctl stop mybot
```

**3. Сохранить старое на всякий случай и удалить старую базу**
```bash
cd /opt/express
cp config.py ~/config.py.bak          # там старый токен
mv database.db ~/database.db.old      # старая база больше не нужна
```

**4. Обновить код**
```bash
git checkout -- .                     # убрать локальные правки (токен в config.py и т.п.)
git pull origin main
```

**5. Поставить зависимости** (тем же Python, что в `ExecStart`)
```bash
# если есть venv:
./venv/bin/pip install -r requirements.txt
# если без venv:
pip3 install -r requirements.txt
```

**6. Указать новый токен и свой ID**
```bash
cp .env.example .env
nano .env
```
```env
BOT_TOKEN=новый_токен_от_BotFather
SUPER_ADMIN_ID=ваш_telegram_id
```

**7. Проверить, что сервис запускает `bot.py` из этой папки**
В `systemctl cat mybot` должны быть `WorkingDirectory=/opt/express` и
`ExecStart=/opt/express/venv/bin/python bot.py` (или `/usr/bin/python3 bot.py`). Если меняли файл сервиса:
```bash
sudo systemctl daemon-reload
```

**8. Запустить и посмотреть логи**
```bash
sudo systemctl start mybot
sudo systemctl status mybot           # должно быть active (running)
journalctl -u mybot -f                # логи в реальном времени, ищите «Бот запускается»
```

**9. Проверить в Telegram**
1. Со своего аккаунта напишите боту `/start` — должна открыться админ-панель.
2. Добавьте бота в рабочую группу и напишите там `/setgroup`.
3. Со второго аккаунта (не админа) напишите боту `/start` и любой текст — сообщения появятся в группе.
4. В группе ответьте реплаем на пересланное сообщение — ответ придёт второму аккаунту, на ответе появится 👍.
5. Откройте 📊 Статистика в панели — там будет 1 пользователь.

**Если не запускается:** `journalctl -u mybot -n 50` покажет ошибку. Частые причины: неверный токен
в `.env`, не установлены зависимости (`No module named aiogram` / `dotenv`), запущен второй экземпляр
бота с тем же токеном (ошибка `Conflict: terminated by other getUpdates`).

## 📁 Структура

```
bot.py              # запуск, порядок роутеров, антифлуд
config.py           # настройки из .env
database.py         # SQLite
texts.json          # тексты по умолчанию
texts.py            # подстановка текстов (БД важнее texts.json)
filters.py          # проверки: админ, супер-админ, рабочая группа
middleware.py       # антифлуд/антиспам (только для клиентов в личке)
handlers/
  panel.py          # админ-панель на кнопках
  admin.py          # текстовые команды админа, бан, управление админами
  group.py          # ответы реплаем из группы клиенту
  user.py           # пересылка сообщений клиента в группу
  common.py         # общие помощники (имена, группа, повтор при лимитах Telegram)
```
