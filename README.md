# 🛍 Telegram Бот Приёма Заказов

Модульный бот для приёма заказов, который пересылает заявки в закрытую группу продавцов и автоматически отправляет ответы пользователям.

## 📋 Возможности

- ✅ **Приём заказов** - пользователи отправляют текстовые заявки
- ✅ **Пересылка в группу** - каждая заявка красиво оформлена и отправлена в группу продавцов
- ✅ **Автоматические ответы** - продавцы отвечают через Reply, ответ идёт пользователю
- ✅ **Блокировка пользователей** - администраторы могут блокировать пользователей
- ✅ **Админ-панель** - полное управление ботом:
  - Редактирование приветственного сообщения (текст + фото)
  - Управление сообщением "Топ недели"
  - Управление администраторами
  - Конфигурация рабочей группы
  - Поиск пользователя и просмотр истории
  - Статистика
- ✅ **Anti-Flood** - защита от спама (1 сообщение в 5 секунд)
- ✅ **Часовой пояс** - все даты/время в UTC+6 (Казахстан)

## 🛠 Технический стек

- **Python** 3.12+
- **Aiogram** 3.30.0
- **SQLite** база данных
- **Модульная архитектура** - легко расширяемая структура

## 📁 Структура проекта

```
bot.py                 # Запуск бота, подключение роутеров
config.py              # TOKEN, SUPER_ADMIN_ID, DATABASE_PATH
database.py            # Работа с SQLite
texts.json             # Все тексты и Premium Emoji
middleware.py          # Проверка прав, антифлуд, часовые пояса
start.py               # /start, приветствие, "Топ недели"

orders.py              # Приём заказов
replies.py             # Ответы из группы пользователям
inline_kb.py           # Inline-кнопки
admin.py               # Админ-панель
admin_states.py        # FSM админ-панели
utils.py               # Вспомогательные функции
database.db            # SQLite база данных (создаётся автоматически)
```

## 🚀 Установка и запуск

### 1. Клонирование/распаковка проекта
```bash
# Распаковать архив
unzip telegram-bot.zip
cd telegram-bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Конфигурация
Отредактируйте `config.py`:

```python
TOKEN = "YOUR_BOT_TOKEN_HERE"  # Токен от @BotFather
SUPER_ADMIN_ID = 123456789      # Ваш User ID
DATABASE_PATH = "database.db"
```

Как получить свой User ID: отправьте боту сообщение и он будет показан в админ-панели.

### 4. Запуск бота
```bash
python bot.py
```

## 📖 Использование

### Для пользователей

1. **Отправить заказ**: нажмите "📝 Сделать заказ" и отправьте текстовое сообщение
2. **Топ недели**: нажмите "🏆 Топ недели" чтобы увидеть лучшие предложения
3. **Получить ответ**: продавцы ответят вам автоматически

⚠️ **Только текстовые сообщения поддерживаются!**

### Для администраторов

Команда: `/admin`

#### 👋 Приветственное сообщение
- Редактировать текст (поддерживает `{first_name}` и `{last_name}`)
- Добавить/заменить фото
- Удалить фото
- Просмотреть текущее

#### 🏆 Топ недели
- Изменить сообщение (текст, ссылки, эмодзи)
- Просмотреть текущее

#### 👮 Администраторы
- Добавить администратора (по User ID)
- Удалить администратора
- Просмотреть список

#### 👥 Рабочая группа
- Изменить ID группы (где будут поступать заявки)
- Просмотреть текущий ID
- Проверить подключение

#### 🔎 Информация о пользователе
- Поиск по User ID
- Просмотр: имя, username, первое обращение, кол-во заявок, статус
- История всех обращений пользователя

#### 📊 Статистика
- Кол-во пользователей
- Кол-во обращений
- Кол-во заблокированных
- Кол-во администраторов

## 📝 Рабочая группа

Как настроить?

1. Создайте закрытую группу в Telegram
2. Добавьте бота в группу с правами на отправку сообщений
3. В админ-панели нажмите "👥 Рабочая группа" → "✏️ Изменить ID группы"
4. Отправьте ID группы (отрицательное число, например: `-1001234567890`)
5. Проверьте подключение

**Как ответить пользователю:**
- В группе на сообщение бота нажмите Reply
- Напишите ответ (только текст!)
- Ответ автоматически отправится пользователю

## 🚫 Блокировка пользователей

**Заблокировать:**
- В группе под заявкой нажмите кнопку "🚫 Заблокировать" (только для админов группы)
- Пользователь больше не сможет отправлять заказы

**Разблокировать:**
- Команда в группе: `/unban USER_ID`
- Например: `/unban 123456789`

## 📊 База данных

SQLite база данных содержит:
- **users** - пользователи и их данные
- **orders** - все заявки
- **admins** - список администраторов
- **settings** - конфигурация (приветствие, топ, группа, etc)
- **blocks** - заблокированные пользователи
- **stats** - счётчики

## 🔧 Кастомизация

### Изменить тексты
Отредактируйте `texts.json`. Все тексты централизованы там.

### Добавить Premium Emoji
1. В `texts.json` добавьте в раздел `premium_emojis`:
```json
"custom_name": "emoji_id_from_telegram"
```
2. Используйте в системных сообщениях через `utils.get_emoji()`

### Расширить функциональность
Проект полностью модульный:
1. Создайте новый `module.py` с роутером
2. Подключите его в `bot.py` через `dp.include_router()`

## 🐛 Решение проблем

**Бот не отправляет в группу?**
- Проверьте ID группы в админ-панели
- Убедитесь, что бот добавлен в группу
- Проверьте подключение через админ-панель

**Ответы не приходят пользователям?**
- Убедитесь, что продавец отвечает через Reply (нажмите Reply на сообщение)
- Проверьте, что ответ - текстовый

**Anti-Flood срабатывает?**
- Это нормально, защита от спама. Попробуйте через 5 секунд.
